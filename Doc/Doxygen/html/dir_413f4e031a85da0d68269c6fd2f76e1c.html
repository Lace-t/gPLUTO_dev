file  array_reconstruct.cpp
 Reconstruct an array Q(i,j,k) along a given direction, defining left and right values at the interfaces qL and qR. qL and qR are unique memory portion of data->sweep->vL and data->sweep->vR respectively, where the offset is determined by the variable nv. In fact, all consecutive calls to ArrayReconstruct<>() have different values of nv. In this way we recycle the structures sweep used in Reconstruct().
