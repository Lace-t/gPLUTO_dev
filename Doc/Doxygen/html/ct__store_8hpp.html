Detailed Description

Collections of inline function used to store emf-related components during Riemann solvers.

Here emf->e (and emf->e_dff) are matrices containing the components of electric field or the velocity (depending on the scheme). During the x1-sweep, for instance, {n,t,b} = {x,y,z} we have 

when dir = DIRn = IDIR:  (Bxn, Bxt, Bxb) = (Bx, By, Bz)
emf->e[DIRb][DIRn] = emf->e[KDIR][IDIR] = -flux(BXt)  = Ez
emf->e[DIRt][DIRn] = emf->e[JDIR][IDIR] =  flux(BXb)  = Ey 

when dir = DIRn = JDIR:  (Bxn, Bxt, Bxb) = (By, Bz, Bx)
emf->e[DIRb][DIRn] = emf->e[IDIR][JDIR] = -flux(BXt)  = Ex
emf->e[DIRt][DIRn] = emf->e[KDIR][JDIR] =  flux(BXb)  = Ez 

when dir = DIRn = KDIR:  (Bxn, Bxt, Bxb) = (Bz, Bx, By)
emf->e[DIRb][DIRn] = emf->e[JDIR][KDIR] = -flux(BXt)  = Ey
emf->e[DIRt][DIRn] = emf->e[IDIR][KDIR] =  flux(BXb)  = Ex

or, if we store velocities: 

 when dir = DIRn = IDIR:  
 emf->e[DIRb][DIRn] = +vy
 emf->e[DIRt][DIRn] = -vz

 when dir = DIRn = JDIR:  
 emf->e[DIRb][DIRn] = +vz
 emf->e[DIRt][DIRn] = -vx

 when dir = DIRn = KDIR:  
 emf->e[DIRb][DIRn] = +vx
 emf->e[DIRt][DIRn] = -vy

Signs are taken so that the final composition formula for a UCT-like scheme are of the type 

Ez = (aL*vL*BL + aR*vR*BR) +- (dR*BR - dL*BL)
