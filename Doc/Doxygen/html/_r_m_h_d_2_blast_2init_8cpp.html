Detailed Description

Set the initial condition for the relativistic magnetized blast wave problem in 2D or 3D. It consists of a highly pressurized region inside a circle (in 2D) or a sphere (in 3D) embeddd in a static uniform medium with lower pressure. The magnetic field is constant and threads the whole computational domain.

\[ (\rho,\, p) = \left\{\begin{array}{lcl} (\rho_{\rm in},\, p_{\rm in}) & \quad\mathrm{or}\quad & r < r_c \\[0.5em] (\rho_{\rm out},\, p_{\rm out}) & \quad\mathrm{or}\quad & r \ge r_c \end{array}\right. \,,\qquad |\vec{B}| = B_0 \]

\[ \vec{B} \]

In 3D, a linear smoothing is applied in the region \( r_c<r<1\). The input parameters used in this problem are:

  1. inputParam[PRS_IN]: pressure inside the initial circular (2D) or spherical (3D) region.
  2. inputParam[PRS_OUT]: ambient pressure
  3. inputParam[RHO_OUT]: ambient density
  4. inputParam[BMAG]: magnetic field intensity
  5. inputParam[THETA]: angle between mag. field and z-axis (Cartesian only )
  6. inputParam[PHI]: angle between mag. field and xy-plane (Cartesian only)
  7. inputParam[RADIUS]: radius of the initial over-pressurized region.

The domain, in each direction, spans over a grid of [-6.0,6.0] in all tests but #1 and #2, where a smaller grid of [-0.5,0.5] in all directions is used. Consequently, the inputParam[RADIUS] is set to 0.08 in the tests #1 and #2 and to 0.8 in all the other tests.

Note that a given choice of parameters can be re-scaled by an arbitrary factor \(\eta\) by letting \( \{\rho,\, p\} \to \eta^2\{\rho,\,p\},\, B \to \eta B \).
