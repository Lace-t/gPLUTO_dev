Detailed Description

  • RBoxDefine() is used to set the box extent in terms of six indices (beg..end for each direction) and the variable location inside the cell.
  • RBoxSeepSet() is used to set normal, tangent and binormal indices with respect to the specified (sweeping) direction. The convention is here respects the fastest running index, (i,j,k) -> (j,i,k) -> (k,i,j) . Useful for sweeping along different directions during the time stepping routines.
