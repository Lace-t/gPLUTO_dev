Forward and central finite differences macros.

The following set of macros provide a compact way to perform two-point, undivided finite difference operations in a specified direction. Differences can be either forward or central. For instance, FDIFF_X2(Q,i,j,k) will compute a forward difference of Q in the y direction, (Q[j+1]-Q[j]), while CDIFF_X3(Q,i,j,k) will compute a central different approximation of Q in the z direction: (Q[k+1] - Q[k-1])/2.

#define OoT   0.08333333333
 
#define FDIFF_X1(Q, i, j, k, var)   (Q(i+1,j,k,var) - Q(i,j,k,var))
 
#define CDIFF_X1(Q, i, j, k, var)   (0.5*(Q(i+1,j,k,var) - Q(i-1,j,k,var)))
 
#define CDIFF4_X1(Q, i, j, k, var)   (OoT*(Q(i-2,j,k,var) + 8.0*(Q(i+1,j,k,var) - Q(i-1,j,k,var)) - Q(i+2,j,k,var)))
 
#define FDIFF_X2(Q, i, j, k, var)   (Q(i,j+1,k,var) - Q(i,j,k,var))
 
#define CDIFF_X2(Q, i, j, k, var)   (0.5*(Q(i,j+1,k,var) - Q(i,j-1,k,var)))

Spatial averages macros.

The following set of macros provide a compact way to perform multi-D averages from cell centered values to interfaces. For instance, AVERAGE_X(q,k,j,i) will simply take the arithmetic average betwen q(i) and q(i+1) at the i+1/2 interface. Likewise, AVERAGE_YZ(q,k,j,i) will produce an average at the j+1/2 and k+1/2 edge.

#define AVERAGE_X(q, i, j, k)   (0.5*(q(i,j,k) + q(i+1,j,k)))
 
#define AVERAGE_Y(q, i, j, k)   (0.5*(q(i,j,k) + q(i,j+1,k)))
 
#define AVERAGE_XY(q, i, j, k)   (0.5*(AVERAGE_X(q,i,j,k) + AVERAGE_X(q,i,j+1,k)))
 
#define AVERAGE_Z(q, i, j, k)   (0.5*(q(i,j,k) + q(i,j,k+1)))
 
#define AVERAGE_XZ(q, i, j, k)   (0.5*(AVERAGE_X(q,i,j,k) + AVERAGE_X(q,i,j,k+1)))
 
#define AVERAGE_YZ(q, i, j, k)   (0.5*(AVERAGE_Y(q,i,j,k) + AVERAGE_Y(q,i,j,k+1)))
 
#define AVERAGE_XYZ(q, i, j, k)   (0.5*(AVERAGE_XY(q,i,j,k) + AVERAGE_XY(q,i,j,k+1)))

ARRAY_STRIDES(grid, dir, nX, nY)

Set stride parameters used to linearize multidimensional grid data into contiguous 1D sweep arrays.

The macro defines: nX = total number of points along the sweep direction dir (length of a single 1D sweep) nY = total number of points along the first transverse direction

These parameters are used by sweep routines to compute the linear offset of a given sweep line as:

offset = nX * ( t1 + nY * t2 )

where (t1, t2) are the two indices transverse to the sweep direction.

Current ordering used in sweep buffers:

IDIR (sweep along i): offset = NX * ( j + NY * k )

JDIR (sweep along j): offset = NY * ( i + NX * k )

KDIR (sweep along k): offset = NZ * ( i + NX * j )

This layout stores all 1D sweeps contiguously in memory, enabling direction-independent algorithms and efficient execution on CPUs, GPUs, and MPI buffers.

NOTE: The macro does not perform the full 3D-to-1D mapping by itself; it only provides stride information required by the calling code.

#define BOX_INDEX (   box,

  k

Value:
( (i - (box).ibeg) + (box).nx1* \

Convert 3D grid coordinates (i,j,k) into a 1D linear array index suitable for flattened contiguous storage. The mapping assumes a structured box with row-major ordering: i varies fastest, followed by j, then k.

Equivalent mapping index = (i - ibeg) + nx1 * ( (j - jbeg) + nx2 * (k - kbeg) )

The BOX_LOOP() macro implements a loop over (i,j,k) in a rectangular portion of the domain with indices defined by the (pointer to) RBox structure B. The BOX_STAG_LOOP() loops over all the edges of the domain and it can be also used to loop over staggered fields with a minimal extra cost. The BOX{I,J,K}_LOOP() allows to travel across the box by including one extra point in the direction of staggering.

#define DIM_EXPAND (   a,
  b,
  c 
)    DIM1(a) DIM2(b) DIM3(c)

Allows to write dimension-ndependent expressions involving vectors by evaluating as many arguments as the number of DIMENSIONS. The result is that only the first argument will be compiled in 1D, the first two arguments in 2D and all of them in 3D. As an example:

1 DIM_EXPAND(v[VX1] = 1.0; ,
2  v[VX2] = 5.0; ,
3  v[VX3] = -4.0; )

becomes

1 v[VX1] = 1.0;

when DIMENSIONS is equal to 1 or

1 v[VX1] = 1.0;
2 v[VX2] = 5.0;

when DIMENSIONS is equal to 2 or

1 v[VX1] = 1.0;
2 v[VX2] = 5.0;
3 v[VX3] = -4.0;

when DIMENSIONS is equal to 3.

Expand only the 1st, 2nd or 3rd argument based on the value of DIMENSIONS.

The FOR_EACH(p, intList) macro implements a loop over the elements of the array intList->indx (in a similar way to Python lists).

Example:

1 intList list;
2 list.nvar = 3;
3 list.indx[0] = 2;
4 list.indx[1] = 5;
5 list.indx[2] = 17;
6 FOR_EACH(nv, &list) printf ("value is = %d\n",nv);
#define IF_1 (   a)    a

The IF(id, a) macro expands to 'a' if id == 1, and to nothing if id == 0. This is useful for enabling or disabling code fragments at compile time based on preprocessor definitions.
