Detailed Description

WriteData() is the main driver for writing data arrays in any of the available formats (binary, VTK, HDF5, etc...).

  • For .dbl, .flt or .vtk file formats, access to binary files is provided by the functions in bin_io.cpp
  • HDF5 files are handled by hdf5_io.cpp
  • image files are handled by write_img.cpp
  • tabulated ascii files are handled by write_tab.cpp

This function also updates the corresponding .out file associated with the output data format.
