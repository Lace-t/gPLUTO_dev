Detailed Description

This directory contains several 1D shock-tube configurations commonly used for benchmarking of numerical methods. There are 16 input parameters that can be used to specify entirely the left and right states with respect to the discontinuity initially placed at x=1/2. For the left state one has:

  • inputParam[RHO_LEFT]: density for the left state
  • inputParam[VX_LEFT]: normal (x) velocity for the left state
  • inputParam[VY_LEFT]: tangential (y) velocity for the left state
  • inputParam[VZ_LEFT]: tangential (z) velocity for the left state
  • inputParam[BY_LEFT]: tangential (y) magnetic field for the left state
  • inputParam[BZ_LEFT]: tangential (z) magnetic field for the left state
  • inputParam[PR_LEFT]: pressure in the left state

Similar parameters are used to specify the right states. In addition,

  • inputParam[BX_CONST]: normal component of magnetic field (this cannot have jump)
  • inputParam[GAMMA_EOS]: the specific heat ratio

The IDEAL equation of state is used. The available configurations are taken from
