Detailed Description

Computes the curl (J) of a vector (V) using a cross-like stencil:

  • when V is edge-centered, J will be face-centered
  • when V is face-centered, J will be edge-centered
  • when V is cell-centered, J will be also face-centered
  • In Cartesian geometry:

    \[ B_x = \pd{A_z}{y} - \pd{A_y}{z} \,,\quad B_y = \pd{A_x}{z} - \pd{A_z}{x} \,,\quad B_z = \pd{A_y}{x} - \pd{A_x}{y} \]

  • In Cylindrical geometry:

    \[ B_R = \frac{1}{R}\pd{A_z}{\phi} - \pd{A_\phi}{z} \,,\quad B_\phi = \pd{A_R}{z} - \pd{A_z}{R} \,,\quad B_z = \frac{1}{R}\pd{(RA_\phi)}{R} - \frac{1}{R}\pd{A_R}{\phi} \]

  • In spherical geometry:

    \[ B_r = \frac{1}{r\sin\theta}\pd{(\sin\theta A_\phi)}{\theta} - \frac{1}{r\sin\theta}\pd{A_\theta}{\phi} \,,\quad B_\theta = \frac{1}{r\sin\theta}\pd{A_r}{\phi} - \frac{1}{r}\pd{(rA_\phi)}{r} \,,\quad B_\phi = \frac{1}{r}\pd{(rA_\theta)}{r} - \frac{1}{r}\pd{A_r}{\theta} \]

For instance, when V == A (vector potential) in CT-MHD, the convention is the following:

  • Ax1[i,j,k] –> Ax1(0++) \(= A_{x_1, i, j+\HALF, k+\HALF}\)
  • Ax2[i,j,k] –> Ax2(+0+) \(= A_{x_2, i+\HALF, j, k+\HALF}\)
  • Ax3[i,j,k] –> Ax3(++0) \(= A_{x_3, i+\HALF, j+\HALF, k}\)

This routine computes the curl of a generic vector field V = (Vx1, Vx2, Vx3) and stores the result in J = (Jx1, Jx2, Jx3). It supports both cell-centered and face/edge-centered fields using PLUTO/gPLUTO's staggered indexing conventions.

The function is used for:

  • B = curl(A) when the vector potential A is edge-centered
  • J = curl(B) when the magnetic field B is face-centered
  • generic applications where V may be cell-centered (location = CELL_CENTER)

Depending on the output array location_, backward-difference indices '(im, jm, km)' refer to:

  • face/edge-centered V -> backward index equals forward index (im = i)
  • cell-centered V -> backward index shifted by 1 (im = i-1)

The routine is geometry-aware and supports:

  • Cartesian
  • Cylindrical (r, phi, z)
  • Spherical (r, theta, phi)
Parameters
[in]VArray of three Ary3D objects containing the components of the input vector field V.
[out]JArray of three Ary3D objects where the components of curl(V) will be stored.
[in]gridPointer to grid structure containing metric, spacing, and precomputed cell-interface coordinates (x1p, x1m, ...).
