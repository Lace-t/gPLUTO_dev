Detailed Description

The function SetOutput() sets, for each output data type (DBL, FLT, VTK etc..), the default attributes of the corresponding Output structure. These include the variable name, a pointer to the actual Ary4D or Ary3D class, the centering of the variable (center/staggered), a conditional inclusion flag (telling if the corresponding variable has to be written in the specified format), and so on.

Variables names are stored in output->var_name[nv] in sequential order with the following convention: 

nv = {0 ... NVAR-1}  {NVAR ... NVAR + ns*DIM-1} {NVAR + ns*DIM + Vuser...}
     Zone-centered       Staggered Fields           User-defined
          ^                      ^                        ^

Vary4D *Vary3D[nv-NVAR] *Vary3D[nv-NVAR]

Vary4D points to different Ary4D depending on the integration method: 

output->Vary4D = *(data->Uc);  (High-Order)
output->Vary4D = *(data->Vpc); (2nd order)

The function SetOutputVar() can be used to include or exclude a given variable to be written using a particular output format.

The function LinkUserVar() should be used from the ComputeUserVar() function to link a user-defined Ary3D into a specified output.
