Detailed Description

The EMF structure is used to pull together all the information necessary to build / use the electromotive force used to update the staggered components of magnetic field.

Field Documentation

Ary3D EMF::e[3][3]

Store either flux or velocity components. The 1st index refers to the vector component while the 2nd index indicates the sweep direction. For instance, e[IDIR][JDIR] is the y-component of electric field stored at x1 faces. (see also ct_store.hpp).
