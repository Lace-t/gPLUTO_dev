Detailed Description

Compute the Poynting vector at zone faces using the upwinded emf. This function is called only when:

  • CT_ENERGY_CORRECTION == 2 (average of Poynting flux): in this case the Poynting flux is computed by averaging the Poynting vector at edges:

    F(i-1/2) = < EB > = [ (EB)^NW + EB^(SW) ]/2

  • CT_ENERGY_CORRECTION == 3 (Poynting flux of average): in this case the Poynting flux is computed by averaging the electric and magnetic fields and the computing the Poynting flux:

    F(i-1/2) = < E > < B > = [ (E)^NW + EB^(SW) ][ (E)^NW + EB^(SW) ]/4
